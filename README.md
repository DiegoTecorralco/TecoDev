Bienvenido al repositorio de mi sitio web personal, **TecoDev**. Este proyecto es mi carta de presentación como Desarrollador de Software Multiplataforma. Está diseñado para mostrar mis habilidades, proyectos, formación y proporcionar una vía de contacto directa, todo en una experiencia moderna, interactiva y completamente responsiva.

Puedes ver el sitio en vivo aquí: **https://teco-dev.vercel.app/** 

---

## Características Principales

*   **Diseño Moderno y Atractivo:** Interfaz limpia con una paleta de colores vibrantes (morados/azules) y tipografías modernas (Poppins, Raleway).
*   **Totalmente Responsive:** Adaptado perfectamente a dispositivos móviles, tablets y pantallas de escritorio.
*   **Tema Claro/Oscuro:** Sistema de cambio de tema con detección de preferencia del sistema y persistencia en `localStorage`.
*   **Animaciones Interactivas:**
    *   Cursor personalizado con efectos en elementos interactivos.
    *   Partículas flotantes en el fondo del Hero.
    *   Iconos de tecnologías flotando.
    *   Efectos de aparición suave al hacer scroll.
    *   Contadores animados en las estadísticas.
*   **Interactividad:**
    *   Menú móvil tipo "Hamburguesa".
    *   Scroll suave a las secciones.
    *   Botón para volver al inicio.
    *   Formulario de contacto funcional (integrado con Formspree).
    *   Notificaciones emergentes personalizadas (éxito/error).
*   **Rendimiento:** Código optimizado y estructura semántica.
